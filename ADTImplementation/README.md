# Abstract Data Type Implementation
For each ADT, there is a header file declares all function can be used, a c file implementing those function and a main file contains some test cases demonstrating how the data structure should work.

## Contents
- Stack
- Queue
- Symbol Table

## Contribute to Implementation
There are two helper shell script:
- `./buildADT.sh <ADT>`: Compile the ADT and run the respective main function
- `./createADT.sh <ADT>`: Create `ADT.h`, `ADT.c` and `ADTMain.c` file from template
