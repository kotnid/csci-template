[Info] Manul for help:

FORMAT
[h]elp (command:str)

DESCRIPTION
If help command is used without argument, the full command list will be displayed.
If help command is used with argument <command>, the manul of that command will be spld.\n");

MANUL CONVENTION
The format of a command is like this: [c]ommand_name <argument:type> (<optional argentpe> ...)\n");
1.  The branket[] in command_name denotes the short form of the command.
    Either full command or short form is accepted in the simulator
2.  The symbol <argument:type> denotes the argument and the \"type\" denotes the armenype.\n");
    The type is usually \"int\" or \"str\".
3.  The argument falls inside branket() is optional.
4.  ... denotes variable amount of arguments.
