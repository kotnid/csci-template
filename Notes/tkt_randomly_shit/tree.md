## Terminologies
#### height 
- height count from 0 and started from null
- root has height 1

#### parent/ children 

#### siblings 
- same parent 

#### ancestor/ de-scendent 

#### interior nodes/leaves
- have child and no child 

#### subtree

#### Binary Tree
- node has 0-2 children 
- node except root can call left/right child of its parent 

#### Binary Search Tree
- key values are unique 
- key value must be greater than all left-subtree nodes, and less then all right-subtree nodes 

#### Balanced Binary Search Tree
- If insertion is bad (E.g. [1,2,3,4,5]), nodes will go into one side, tree is not balanaced
- A tree is balanced if at each node the height of the left and right subtree is differ by atmost one 

#### Adelson-Velskii and Landis Tree (AVL Tree)
- binary search tree with balanced condition
